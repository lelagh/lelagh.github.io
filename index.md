## Sile's AwakeCE Tools

These are here because they're useful to me, possibly also, dear reader, they will be useful to you:

* [Colour Code Preview](https://lelagh.github.io/awakemud-strings/)
  
  See what restrings (and descriptions!) will look like with colour codes before using karma on them.

* [XTERM Color Code Equivalents Gist](https://lelagh.github.io/color-codes/)
  
  Just a gist of which ^\[Fxyz\] codes correspond to the MUD's standard colour codes.

* [Deckbuilder](https://lelagh.github.io/deckbuilder/)
  
  Plan/calculate what you can load into active memory on a cyberdeck at various MPCP ratings.

* [Fixer Percentages](https://lelagh.github.io/fixer/)

  Figure out the odds of placing an order are going to be (fixer "drop chance" calculator).

* [Successes Calculator](https://lelagh.github.io/successes/)

  Gives you the percentage chance that x dice will give at least y successes.
