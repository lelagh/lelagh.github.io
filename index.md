## Sile's AwakeCE Tools

* [Colour Code Preview](https://lelagh.github.io/awakemud-strings/)
  
  See what restrings and descriptions will look like with colour codes before spending karma on them.

* [XTERM Color Code Equivalents Gist](https://lelagh.github.io/color-codes/)
  
  Just a gist of which ^\[Fxyz\] codes correspond to the MUD's standard colour codes.

* [Deckbuilder](https://lelagh.github.io/deckbuilder/)
  
  Plan/calculate what you can load into active memory on a cyberdeck at various MPCP ratings.
